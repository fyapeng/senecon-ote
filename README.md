# SenEcon / OTE

《最优运输理论》的出版物展示页与资源下载页。

页面定位为一本学术教材的数字书籍封面：展示书籍简介、前言节选、三卷目录、PDF 下载和配套代码说明。完整正文继续以 PDF 作为正式阅读版本，不转换为整站 HTML。

## Local development

```powershell
npm install
npm run dev
npm run build
npm run test:sites
```
